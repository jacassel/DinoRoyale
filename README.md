# Dinosaur Battle — Pre-Alpha 0.1

A local single-player dinosaur combat prototype. Development is in progress.

Engine: Unreal Engine 5.8.2. Original asset source: Blender 5.2.2 LTS.

The project is built locally with no commercial assets, online services, or paid APIs.

## Controls (implementation in progress)

WASD movement, mouse camera, Space jump, hold Q defensive brace, LMB quick attack,
hold/release RMB charged attack. E eat. 1/2/3 choose species. Escape selection menu.

See DESIGN.md, TEST_LOG.md, KNOWN_ISSUES.md, and ROADMAP.md for development status.
